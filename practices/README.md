## 新增案例

1. 复制模板，在本目录创建具有明确主题的 Markdown 文章。
2. 写清目标、环境与前置条件、步骤、结果和踩坑，记录实际使用的版本或提交。
3. 按文章从头复现，保留必要的脱敏输出或截图，明确未验证的部分。
4. 将文章链接添加到上方案例索引；配图按[资源约定](../assets/README.md)存放。

不要提交令牌、密钥、私人聊天内容或未经授权公开的数据。
