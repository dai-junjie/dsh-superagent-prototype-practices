# 实践案例

收录能够从头复现、独立验证结果的 dsh-superagent-prototype 实践案例。

## 案例索引

当前提供两项必做实践和一项选做实验，均为**尚未执行的实践方案**，不是已验证案例：

| 顺序 | 实践 | 重点 |
| --- | --- | --- |
| 1 · 必做 | [从消息到文档 PR](01-message-to-pr.md) | 走通请求、交付与人工审阅 |
| 2 · 必做 | [授权边界对照](02-authorization-boundary.md) | 同类请求在固定策略下是否接纳 |
| 3 · 选做 | [隔离环境中断恢复](03-interruption-recovery.md) | 记录工作中重启后的恢复与人工介入 |

建议按顺序阅读，先做第一项，再决定是否具备后续实验的前置条件。每篇都给出输入、预期、操作步骤和待填写的实际记录；不要把预期复制成结果。

分享时围绕“请求怎样变成可审阅结果”组织材料：用实践一呈现交付链路，用实践二解释授权边界，有隔离环境再用实践三讨论恢复局限。文章理念、公开实现文档和实际观察分别标注；没有执行证据时只介绍实验设计。

[最小实践模板](_template.md)可用于新增主题。

## 新增案例

1. 复制模板，在本目录创建具有明确主题的 Markdown 文章。
2. 写清目标、环境与前置条件、步骤、结果和踩坑，记录实际使用的版本或提交。
3. 按文章从头复现，保留必要的脱敏输出或截图，明确未验证的部分。
4. 将文章链接添加到上方案例索引；配图按[资源约定](../assets/README.md)存放。

不要提交令牌、密钥、私人聊天内容或未经授权公开的数据。
