# 基础练习

这些是用于理解链路和边界的动手练习，均**尚未执行**，不是实测报告，也不等于生产实践收益。

- [消息到文档 PR](01-message-to-pr.md)：用小任务走通请求、交付与人工审阅。
- [授权边界对照](02-authorization-boundary.md)：在固定策略下比较同类请求的接纳情况。
- [隔离环境中断恢复](03-interruption-recovery.md)：选做，观察受控重启；缺少独立部署和备份恢复条件时跳过。

原有步骤、预期和待填写的记录表保留，方便动手验证技术机制。先做最小练习，再结合[生产实践案例](../README.md#生产实践)判断这些机制对团队工作的实际价值；不要把练习成功直接当作效率或可靠性结论。
